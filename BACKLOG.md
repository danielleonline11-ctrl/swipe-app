# swipe-app — backlog

## v0.3 candidates

### Tap-to-note before swipe
Card should be tappable to expand and add a freeform note before swiping. Requires a tap-vs-swipe gesture split so a tap doesn't register as a partial swipe. Note persists with the item.

### Multi-list load
Picker goes single-select → multi-select; selected lists merge into one deck (e.g. This Week + Wedding). Each card carries a visible source tag so the origin list is clear mid-swipe.

### Engage → optional timer
On a swipe-right to "engage," pause briefly mid-flight and offer "Start a timer now?" Quick yes/no, defaults to NO if flicked past so fast-sorting isn't interrupted. Yes = starts a focus timer on that task. (This is the bridge to the paper focus page — a started timer = a drawn timebox.)
